# Hardware across the captured devices

The firmware collection spans several products and platforms. A shared HomeOS component or device-tree label does not establish identical boards, ports or silicon. These pages distinguish observed hardware, published specifications and facts inferred from firmware.

- [Beacon G6](beacon-g6.md): Cortina CA8289 Ethernet router; G6 HomeOS 24.02 and 24.04 captures and live hardware observations.
- [XS-2426X-A](xs-2426x-a.md): Cortina fibre ONT; HomeOS 24.03 firmware and NAND captures.
- [XS-2426G-B](xs-2426g-b.md): older fibre ONT; R21.04 and R23.03 firmware-bank images.
- [Beacon 9](beacon-9.md): Qualcomm-based router; HomeOS 25.03 firmware and live/eMMC captures.

See [storage layouts](../storage-and-flash/README.md) for the partition maps and [firmware inventory](../firmware-versions-and-builds/README.md) for build identities. Each page covers the platform, ports, memory, radios, storage and debug interfaces. The amount of live and physical-board evidence differs between models; [model-specific knowledgebases](../../knowledgebases/hardware.md) retain the full research context.
